# 新 Mac 电脑高效使用指南

刚拿到一台新的 Mac，最重要的不是马上安装一堆软件，而是先建立一套顺手的使用习惯。只要把搜索、快捷键、文件整理、备份和任务管理这几件事做好，Mac 会很快变成一台真正省心、高效的工作设备。

这篇文章整理了一份适合新 Mac 用户的使用指南，可以边用边查，也可以作为自己的电脑初始化清单。

## 一、先完成基础设置

### 1. 登录 Apple ID 并开启 iCloud

建议先登录 Apple ID，然后检查 iCloud 设置。

推荐开启：

- iCloud 云盘：同步桌面、文稿和常用文件。
- 照片：如果你用 iPhone，照片会自动同步。
- 钥匙串：保存网站密码、Wi-Fi 密码和验证码。
- 查找：电脑丢失时可以定位、锁定或抹掉。

设置路径：

```text
系统设置 > Apple ID > iCloud
```

### 2. 调整触控板

Mac 的触控板非常强，建议开启这些功能：

- 轻点来点按：轻触即可点击。
- 辅助点按：双指点按相当于右键。
- 三指拖移：拖窗口、选文字更轻松。
- 自然滚动：不习惯的话可以关闭。

设置路径：

```text
系统设置 > 触控板
系统设置 > 辅助功能 > 指针控制 > 触控板选项
```

### 3. 精简 Dock

Dock 不需要放太多应用，只保留最常用的即可。

建议保留：

- Finder
- Safari 或 Chrome
- 微信、飞书、钉钉等沟通软件
- 备忘录
- 日历
- VS Code、Cursor 或其他常用工作软件

不常用的应用可以从 Dock 移除，这不会卸载应用。

## 二、必须掌握的快捷键

### 1. 通用快捷键

| 快捷键 | 功能 |
|---|---|
| Command + C | 复制 |
| Command + V | 粘贴 |
| Command + Z | 撤销 |
| Command + Shift + Z | 重做 |
| Command + A | 全选 |
| Command + S | 保存 |
| Command + F | 查找 |
| Command + W | 关闭当前窗口或标签页 |
| Command + Q | 退出应用 |
| Command + Tab | 切换应用 |
| Command + ` | 在同一个应用的多个窗口间切换 |

### 2. 截图快捷键

| 快捷键 | 功能 |
|---|---|
| Command + Shift + 3 | 截取整个屏幕 |
| Command + Shift + 4 | 截取选定区域 |
| Command + Shift + 5 | 打开截图和录屏工具 |
| Command + Shift + 4，然后按空格 | 截取某个窗口 |

截图默认保存在桌面。可以通过 `Command + Shift + 5` 打开选项，修改截图保存位置。

### 3. Finder 文件管理快捷键

| 快捷键 | 功能 |
|---|---|
| Command + N | 新建 Finder 窗口 |
| Command + Shift + N | 新建文件夹 |
| Command + Delete | 删除文件到废纸篓 |
| Command + I | 查看文件信息 |
| 空格键 | 快速预览文件 |
| Enter | 重命名文件 |
| Command + 上箭头 | 返回上一级文件夹 |

## 三、用好 Spotlight 搜索

Spotlight 是 Mac 的全局搜索工具。

快捷键：

```text
Command + 空格
```

你可以用它做很多事：

- 打开应用。
- 搜索文件。
- 做简单计算。
- 做单位换算。
- 查英文单词。

例如：

```text
128*36
100 USD to CNY
20 cm to inch
```

一个很实用的习惯是：想打开任何东西，先用 `Command + 空格` 搜索。

## 四、建立清晰的文件结构

建议在“文稿”里建立一套固定目录。

```text
文稿/
  工作/
  学习/
  项目/
  资料/
  证件/
  临时/
  归档/
```

使用原则：

- 桌面只放临时文件。
- 下载文件夹每周清理一次。
- 重要文件放进 iCloud 云盘或其他云盘。
- 已完成的项目移动到“归档”。
- 文件名尽量包含日期和主题。

文件名示例：

```text
2026-07-06_购机发票.pdf
2026-07_学习计划.md
客户A_合同_v2.docx
```

## 五、提升窗口和桌面效率

### 1. 多桌面

三指或四指向上滑可以打开调度中心，并新建多个桌面。

可以这样分工：

- 桌面 1：沟通软件。
- 桌面 2：浏览器和资料。
- 桌面 3：写作或编程。
- 桌面 4：娱乐或音乐。

### 2. 分屏

把鼠标停在窗口左上角绿色按钮上，可以选择分屏显示。

适合这些场景：

- 左边看资料，右边写文档。
- 左边网页，右边表格。
- 左边聊天，右边处理文件。

## 六、输入法和文字效率

### 1. 文本替换

设置路径：

```text
系统设置 > 键盘 > 文本输入 > 文本替换
```

可以设置：

| 输入 | 替换为 |
|---|---|
| @@ | 你的邮箱 |
| addr | 常用地址 |
| tel | 手机号 |
| sig | 邮件签名 |

这样可以减少大量重复输入。

### 2. 语音输入

连续按两次 Fn 键，通常可以开启听写。它适合快速记录想法、会议纪要草稿或临时灵感。

设置路径：

```text
系统设置 > 键盘 > 听写
```

## 七、用好备忘录、提醒事项和日历

### 1. 备忘录

适合保存：

- 临时想法。
- 会议记录。
- 旅行计划。
- 购物清单。
- 学习笔记。

建议建立几个文件夹：

- Inbox
- 工作
- 学习
- 生活
- 资料收藏

### 2. 提醒事项

提醒事项适合管理行动，不适合写长文。

推荐清单：

- 今天
- 本周
- 工作
- 生活
- 等待他人

可以直接输入：

```text
明天上午10点提醒我交电费
每周五下午5点提醒我整理下载文件夹
```

### 3. 日历

日历适合放有明确时间的事情：

- 会议。
- 课程。
- 约会。
- 截止日期。
- 旅行安排。

简单来说：提醒事项管“要做什么”，日历管“什么时候发生”。

## 八、安全与隐私

新电脑一定要先做好安全设置。

建议完成：

- 开启登录密码。
- 开启 Touch ID。
- 开启 FileVault 磁盘加密。
- 开启“查找我的 Mac”。
- 不安装来源不明的软件。
- 系统和浏览器保持更新。

常用设置路径：

```text
系统设置 > 触控 ID 与密码
系统设置 > 隐私与安全性 > FileVault
系统设置 > Apple ID > iCloud > 查找我的 Mac
```

密码管理建议使用：

- Apple 钥匙串。
- 1Password。
- Bitwarden。

不要把密码明文写在备忘录、微信收藏或桌面文档里。

## 九、做好备份

### 1. Time Machine

如果有移动硬盘，建议开启 Time Machine。它可以自动备份整台电脑，误删文件或电脑损坏时非常有用。

设置路径：

```text
系统设置 > 通用 > Time Machine
```

### 2. 云端备份

重要文件建议至少有一份云端备份。

可选方案：

- iCloud Drive
- OneDrive
- Google Drive
- Dropbox
- 坚果云

原则很简单：重要资料至少保留两份，特别重要的保留三份。

## 十、推荐安装的软件

### 日常效率

- Chrome：浏览器兼容性强。
- Notion 或 Obsidian：知识管理。
- Raycast：高级启动器和效率工具。
- Rectangle：窗口管理。
- IINA：视频播放器。
- The Unarchiver：解压工具。

### 写作与文档

- Typora 或 MarkEdit：Markdown 写作。
- Microsoft Office 或 WPS：办公文档。
- PDF Expert 或 Adobe Acrobat：PDF 阅读和标注。

### 开发或进阶使用

- VS Code 或 Cursor：代码编辑器。
- iTerm2：终端工具。
- Homebrew：Mac 软件包管理工具。
- Git：版本管理。

如果刚开始用 Mac，不用急着安装太多工具。先把系统自带功能用顺，再逐步增加软件。

## 十一、常见问题处理

### 1. 应用卡住

快捷键：

```text
Command + Option + Esc
```

打开“强制退出应用程序”，选择卡住的应用并退出。

### 2. 电脑变慢

可以检查：

- 是否开了太多浏览器标签页。
- 存储空间是否不足。
- 是否有应用长期占用 CPU。
- 是否刚完成系统更新，后台还在整理数据。

可以打开“活动监视器”查看具体情况。

### 3. 存储空间不够

设置路径：

```text
系统设置 > 通用 > 储存空间
```

优先清理：

- 下载文件夹。
- 废纸篓。
- 大视频文件。
- 重复安装包。
- 不再使用的软件。

## 十二、建议养成的使用习惯

### 每天

- 用 Spotlight 打开应用和文件。
- 随手把任务放进提醒事项。
- 桌面文件当天清理。
- 重要想法先放进备忘录 Inbox。

### 每周

- 清理下载文件夹。
- 整理桌面。
- 归档完成的项目。
- 检查提醒事项和日历。

### 每月

- 检查系统更新。
- 检查软件权限。
- 检查备份是否正常。
- 删除不用的软件。

## 十三、一个简单的日常工作流

每天开始工作时，可以按这个顺序来：

1. 打开日历，看今天固定安排。
2. 打开提醒事项，看今天要完成的任务。
3. 用 Spotlight 打开需要的应用。
4. 把临时想法记到备忘录 Inbox。
5. 当天结束前清理桌面和下载文件夹。
6. 把完成的资料移动到对应项目文件夹或归档。

这套流程并不复杂，但坚持一段时间后，电脑会越来越清爽，找资料和进入工作状态都会更快。

## 结语

Mac 的高效使用不是靠一次性学会很多技巧，而是靠几个稳定习惯慢慢叠加。

最值得先记住的是：

1. 用 `Command + 空格` 搜索和打开一切。
2. 用 `Command + Tab` 快速切换应用。
3. 用空格键快速预览文件。
4. 用提醒事项管理任务。
5. 用固定目录管理文件。
6. 重要资料一定要备份。

先把这些做好，再去尝试 Raycast、自动化、终端和更多进阶工具，会自然很多。
